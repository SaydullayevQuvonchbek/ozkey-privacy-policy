Privacy Policy - OzKey: Ozbek klaviaturasi

Last updated: November 2026

OzKey does not collect, store, or transmit any personal data. We do not log keystrokes, store clipboard history beyond the active session, require user accounts, display advertisements, or share data with third parties.

Translation Feature

The optional translation feature sends selected text to the MyMemory public API (mymemory.translated.net). No personal identifiers are attached. This is triggered only by explicit user action.

Permissions

OzKey requests only the permissions required for a keyboard input method. No permission is used for data collection or tracking.

Children

OzKey does not knowingly collect data from children under 13.
